# Week 2 Day 1 — JavaScript Fundamentals Drills

Solutions to five classic functions, a Kenyan county object, a matatu route system, and a bonus number-to-words converter.

## Files

- `index.js` — All tasks in one file

## Tasks Completed

- **Task 1:** fizzBuzz, reverseString, isPalindrome, findLargest, countVowels
- **Task 2:** Kenyan county object with `displayCounty`, `formatPopulation`, `bordersString`
- **Task 3:** Matatu routes with `cheapestRoute`, `routesThroughStop`, `journeyFare`
- **Bonus:** `numberToWords` — converts 1 to 9,999,999 into shilling words

node index.js
